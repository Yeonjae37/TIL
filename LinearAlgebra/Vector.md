### 2차원 벡터 (평면)
$\vec{\nu} = [\nu_x , \nu_y]$  
$\nu_x$ : x축 방향으로 얼마나 이동하는가  
$\nu_y$ : y축 방향으로 얼마나 이동하는가  


### 3차원 벡터 (공간)
$\vec{\nu} = [\nu_x , \nu_y , \nu_z]$  
$\nu_x$ : x축 방향(가로)으로 얼마나 이동하는가  
$\nu_y$ : y축 방향(세로)으로 얼마나 이동하는가  
$\nu_z$ : z축 방향(위아래)으로 얼마나 이동하는가

### 코드 상의 벡터
1. 벡터 생성: ```python np.array```
2. 성분 접근: ```vector[0], vector[1]``` 등으로 각 성분에 접근
3. 차원 확인: ```vector.shape```로 벡터의 차원 정보 확인
4. 실용적 계산: 평균, 최댓값, 최솟값 등 실제 필요한 계산들

## 벡터 연산 기초
### 벡터 덧셈
$\vec{\nu_1} + \vec{\nu_2} = [3,2] + [1,4] = [4, 6]$

-> 두 벡터의 덧셈이 가능하려면 같은 차원이어야 한다. 2차원 벡터와 3차원 벡터는 더할 수 없다.

### 벡터 뺄셈
$\vec{\nu_1} - \vec{\nu_2} = [3,2] - [2,1] = [1, 1]$

### 벡터 연산의 성질
벡터 덧셈과 뺄셈은 다음과 같은 성질을 만족한다:
1. 교환법칙: $\vec{a} + \vec{b} = \vec{b} + \vec{a}$
2. 결합법칙: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
3. 항등원: $\vec{a} + \vec{0} = \vec{a}$
4. 역원: $\vec{a} + (-\vec{a}) = \vec{0}$

## 스칼라 곱
스칼라 $k$와 벡터 $\vec{v}$의 곱은 벡터의 각 성분에 스칼라를 곱한 것이다.  
$k\cdot\vec{v} = k\cdot[v_1, v_2, ..., v_n] = [k\cdot v_1, k\cdot v_2, ..., k\cdot v_n]$

### 스칼라 곱의 기하학적 의미
1. $k > 1$: 벡터가 $k$배만큼 늘어남 (같은 방향)
2. $0 < k < 1$: 벡터가 줄어듦 (같은 방향)
3. $k = 0$: 영벡터가 됨
4. $k < 0$:  벡터의 방향이 반대가 되고 크기가 $|k|$배가 됨

### 스칼라 곱의 성질
스칼라 곱은 다음 성질들을 만족한다.
1. 결합법칙: $(ab)\vec{v} = a(b\vec{v})$
2. 분배법칙: $a(\vec{u} + \vec{v}) = a\vec{u} + a\vec{v}$
3. 분배법칙: $(a + b)\vec{v} = a\vec{v} + b\vec{v}$
4. 항등원: $1\cdot \vec{v} = \vec{v}$

## 벡터의 norm
### norm의 개념
벡터의 norm은 벡터의 "크기" 또는 "길이"를 나타내는 값이다. 2차원에서는 피타고라스 정리로 쉽게 계산할 수 있고, 고차원에서도 같은 원리를 확장하여 사용한다.

### L2 norm(유클리드 거리)
가장 일반적으로 사용되는 벡터의 크기 측정 방법이다.  
2차원 벡터 $\vec{v} = [v_1, v_2]$의 L2 norm은:   
$|\vec{v}|_2 = \sqrt{v^2_1 + v^2_2}$  
3차원 벡터의 경우:  
$|\vec{v}|_2 = \sqrt{v^2_1 + v^2_2 + v^2_3}$  

일반적으로 n차원 벡터의 L2 norm은:  
$|\vec{v}|_2 = \sqrt{v^2_1 + v^2_2 +...+ v^2_n}$
